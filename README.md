# WebDAV同步应用插件（webdavsync.koplugin）v2.4

KOReader 插件：截图上传 + 多设备阅读进度同步 + 多设备标注（高亮/笔记）同步，均使用 KOReader 已配置的 WebDAV 云存储。

## 安装
1. 把整个 `webdavsync.koplugin` 文件夹复制到两台设备的 `koreader/plugins/`，重启 KOReader。
2. 先在 KOReader「云存储」里配置好 WebDAV 账户（本机坚果云已配置）。

## 功能一：截图上传
1. 在「工具」→「WebDAV同步应用插件」→「上传截图到云端」。
2. 也可用手势触发：设置 → 手势管理器 → 选择任意手势 → 动作选「上传截图到云端」（在「常规」分类）。
3. 只上传 `settings/webdavsync_upload.lua` 中未记录过的新 PNG，可重复点击补传。

## 功能二：多设备阅读进度同步
1. 「工具」→「WebDAV同步应用插件」→「阅读进度同步」子菜单：
   - 上传当前阅读进度
   - 拉取云端阅读进度
   - 自动同步开关（默认开启）
2. 自动同步开启时：打开书自动对比本机与云端进度，以读得更靠前的一方为准；翻页 8 秒后上传；关闭书时上传。
3. 手势同样可绑定「上传阅读进度」「拉取阅读进度」两个动作（在「阅读器」分类）。

## 功能三：多设备标注（高亮/笔记）同步
1. 「工具」→「WebDAV同步应用插件」→「标注同步」子菜单：
   - 上传本书标注到云端
   - 拉取云端标注
2. 手势管理器也可绑定「上传标注」「拉取标注」两个动作（在「阅读器」分类）。
3. 同步的是 KOReader 原生的 `annotations` 数据（高亮位置、颜色、文字、笔记），拉取后高亮会立即刷新显示。

## 标注冲突规则（v2.4 起）
- 拉取时先与本地标注逐条对比：内容完全一致则不改动。
- 标注不同时**只做合并，不做覆盖**：
  - 以本地标注为基础，把云端有而本地没有的标注追加进来；本地原有标注保留不变。
  - 合并后立即写入本地并**反向上传云端**，让云端始终是标注最完整的一份。
  - 手动「上传标注」也会先把云端内容合并到本地再上传，避免误把云端标注变少。
- 同一条标注按「书籍位置 + 样式 + 文字」判重，不会因为顺序不同或重复拉取产生副本。
- 标注记录在账户 `url` 字段 + `koreader-annotations/<书籍摘要>.json`，同一本书两台设备共用一份。
- 标注同步为手动操作，不会在阅读中自动触发，以免影响当前会话。

## v2.4 修复
- 修复拉取标注后 KOReader 卡死/退出的问题：旧版本向刷新队列写入了无效的 `flash` 模式，菜单关闭时触发 `uimanager.lua` 报错；现改为合法的 `ui` 模式。

## 同步规则（阅读进度）
- 同一本书用文档校验和（`partial_md5_checksum`，回退文件名 MD5）匹配，两台设备上需为同一文件。
- 进度记录存于账户 `url` 字段 + `koreader-progress/<书籍摘要>.txt`，内容含位置、百分比、时间戳、设备。
- 拉取时：手动拉取总是跳到云端进度（云端来自本设备时提示跳过）；自动拉取会对比本地与云端进度，分页文档比页码、流式文档比百分比，以读得更靠前（更快）的一方为准；本地更快时保留本地并反向上传到云端，让所有设备收敛到最快进度。
- 分页文档（PDF/DJVU）按页码跳转，流式文档（EPUB 等）按 XPointer 跳转。

## 通用说明
- 地址、账号、密码、远端目录都自动从 `settings/cloudstorage.lua` 读取，插件里不保存凭据。
- 多个 WebDAV 账户时取 `order` 最大的那个；只有一个账户时取它。
- 进度同步开关记录在 `settings/webdavsync_settings.lua`。
